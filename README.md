# SaliBussiness

اپلیکیشن اندروید فروش گزارش‌های امنیتی SaliSecure — کلاینت ایمیل + موتور کمپین بازبینی‌شده.

## قابلیت‌ها
- کلاینت ایمیل: اکانت IMAP، صندوق ورودی، خواندن و پاسخ
- خط لوله‌ی کمپین: ورود دامنه‌ها ← مطابقت گزارش‌های sitest ← غنی‌سازی You.com ← تولید متن AI (hcnsec) ← بازبینی و تأیید دستی ← ارسال با Brevo/SMTP
- پیوست خودکار دو PDF گزارش (فارسی + انگلیسی)
- follow-up، خط لوله‌ی فروش، آمار تجمیعی، لاگ زنده

## ساخت APK
GitHub → Actions → "Build SaliBussiness APK" → Run workflow → دانلود SaliBussiness.apk

## نکته‌ی حقوقی
ارسال فقط به لیست سرنخ‌های خودت (با رضایت یا رابطه‌ی تجاری)؛ بدون ارسال گروهی ناخواسته.
