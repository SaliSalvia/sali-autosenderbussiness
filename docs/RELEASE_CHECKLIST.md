- [ ] تست Golden Set اجرا شد: ۱۰۰ ایمیل نمونه، **۰ عدد/ادعای جعلی**
- [ ] تست «۰ ایمیل بدون تأیید انسان» سبز است (هیچ مسیری جز `APPROVED` به `MailSender` نمیرسد)
- [ ] تست «۰ ارسال تکراری» سبز است (UUID idempotency + lease + retry)
- [ ] فقط ۲ فایل trial دوصفحهای (`_fa` + انگلیسی) الصاق میشود؛ `%PDF` و `pages==2` هنگام ارسال تأیید میشوند
- [ ] حجم هر پیوست ≤ ۴MB و مجموع ≤ ۲۰MB (محدودیت مستند Brevo)
- [ ] `QualityGate` بعد از ویرایش دستی هم اجرا میشود؛ دکمه تأیید تا عبور گیت غیرفعال است
- [ ] خط opt-out در انتهای **همه** ایمیلها (شامل پیگیریها و پاسخهای دستی) وجود دارد
- [ ] فهرست عدم ارسال قبل و بعد از ارسال چک میشود؛ درخواست حذف < ۶۰ ثانیه اعمال میشود
- [ ] هیچ ادعای «تضمین رسیدن به اینباکس»، مهلت ساختگی، تخفیف، تهدید یا `Re:` جعلی در پرامپت/متن نمونه نیست
